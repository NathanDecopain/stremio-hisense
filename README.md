# Stremio for Hisense VIDAA TVs

A lightweight Stremio client for older Hisense VIDAA U TVs, whose browser (Chrome 53, no
WebAssembly) can't run the official Stremio Web. It recreates the look and behaviour of
[stremio-web](https://github.com/Stremio/stremio-web) (GPL-2.0) in plain JavaScript and
talks to Stremio addons and the Stremio API directly.

- Sign in with a code on link.stremio.com; your addons, library and progress sync.
- Board, Discover, Library, Search, details with episodes and streams, and a player with
  subtitles, audio tracks and next-episode autoplay.
- Streams are ranked for the TV: cached debrid files first, formats it can't decode last.
